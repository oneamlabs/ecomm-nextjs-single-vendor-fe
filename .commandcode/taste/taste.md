# Taste

## UI & Design

- Judges UI typography by end-user readability first: display/decorative faces only at large display sizes, functional/card/body copy set in the readable body face at a legible size. Confidence: 0.6
- Favors image-led, editorial layouts — real photography as the visual anchor with copy layered over it (e.g. text over a photo carousel) — and wants the result attractive but not distracting. Confidence: 0.55
- Dislikes airy layouts that waste vertical white space; wants tight section rhythm and no empty grid columns. Confidence: 0.55

## Workflow

- Prefers fixes applied incrementally — one issue at a time, verified before moving on — rather than a single large batch of changes. Confidence: 0.55
